
  # Pravas Sewa

  Pravas Sewa is a travel and citizen-service landing page designed to make essential transport-related information and support more accessible. This project was developed during my first semester of engineering and represents my first website build, marking an early and meaningful step in my journey as a web developer.

  “Small ideas, built with care, can create smoother journeys.”

  ## Project Overview

  The concept is centered around simplifying travel and service-related experiences for users by offering a clean, approachable interface for key information such as services, contact details, and digital assistance. The design focuses on clarity, trust, and usability while reflecting a beginner-friendly approach to front-end development.

  ## Key Features

  - Landing page for a travel and service brand
  - Informative sections highlighting core services
  - Contact and support-focused layout
  - Clean modern styling and responsive design
  - Simple front-end implementation using HTML, CSS, and JavaScript

  ## Tech Stack

  - HTML
  - CSS
  - JavaScript
  - Parcel

  ## How to Run Locally

  1. Install Node.js from the official website: https://nodejs.org/
  2. Open the project folder in VS Code
  3. Run the following commands in the terminal:

  ```bash
  npm install
  npm start
  ```

  4. Open the local preview in your browser, typically at http://localhost:1234

  This was one of my first hands-on projects in web development, created during the early phase of my engineering studies. It reflects a foundational effort in learning layout design, styling, user experience, and front-end structure, and it remains a meaningful part of my learning journey.
